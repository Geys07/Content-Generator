# REKA Studio

Ruang kerja video edukasi untuk kreator Indonesia, terutama pengguna ponsel. Acuan visual: mockup REKA Studio yang telah ditampilkan. Energy 2 / Rhythm 2 / Motion 1.

- Ivory #F6F2EA untuk bidang naskah agar mudah dibaca; graphite #24262A untuk monitor agar batas video jelas.
- Vermilion #B83F28 untuk satu tindakan utama per bagian, bukan seluruh dekorasi. Sage untuk status selesai dengan teks pendamping.
- System sans untuk respons cepat dan huruf Indonesia yang terbaca; ukuran teks form 16px. Angka waktu memakai tabular numerals, bukan judul monospace.
- Desktop: monitor di kiri, tugas aktif di kanan. Ponsel: satu tugas per layar dengan empat tahap di navigasi bawah; tablet memakai ruang baca lebih lebar.
- Galeri memakai contoh visual nyata, bukan ikon yang tidak menggambarkan gaya. Pilihan gaya tidak mengisi naskah.
- Tombol sentuh minimal 48px, jarak 8px. Radius 8px untuk kontrol, 12px untuk dialog dan monitor. Bayangan hanya pada dialog.
- Form baru kosong, label selalu terlihat, placeholder hilang ketika fokus. Nilai proyek yang disimpan tetap dipertahankan.
- Salin prompt langsung ke clipboard; lihat prompt menjadi tindakan terpisah. Validasi setelah tempel; perpindahan hanya setelah data valid diterapkan.
- Animasi UI hanya feedback warna 120ms dan menghormati reduced motion.

## Panduan tambahan
UI UX Pro Max digunakan untuk pencarian sistem desain dan aturan touch/navigation. Hasil sistem desain video-editor mengusulkan landing hero dan palet pink yang tidak sesuai ruang kerja ini. Pencarian lebih spesifik masih bersifat productivity umum; layout/palet mockup di atas menjadi keputusan produk. Hasil UX relevan: ruang antar-target, navigasi tidak menutup konten, kontrol touch yang mudah dijangkau. Anti-Slop UI dan Layout Mobile digunakan selama implementasi dan pemeriksaan.
